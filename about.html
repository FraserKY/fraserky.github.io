Background

Software and controls engineer, working on production embedded software for automotive control systems, and moving into robotics.

Now

What I do

Most of my work has been production embedded software for automotive control systems: C, Simulink, real-time control, and hardware–software integration and debugging at the bench.

I’m in the middle of moving that work across into robotics. It’s the same problem approached from a different end — getting something physical to behave predictably — but the tools are different, so I’ve been learning them by building things rather than reading about them.

The projects on this site are all my own, done in my own time: imitation learning on a robot arm I printed and assembled, field-oriented motor control written from the peripheral up, and whatever comes next. I write up what didn’t work as well as what did, because that’s the part I’d want to read on someone else’s site.
